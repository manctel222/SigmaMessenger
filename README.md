# SigmaMessenger

Бэкенд мессенджера с поддержкой обмена сообщениями в реальном времени.

## Стек технологий
* **Backend:** C#, ASP.NET Core Web API
* **Real-time:** SignalR (WebSockets)
* **База данных:** PostgreSQL, Entity Framework Core
* **Аутентификация:** JWT Bearer, BCrypt

## Реализованный функционал
* Регистрация и аутентификация пользователей с выдачей JWT-токенов
* Создание личных диалогов (с защитой от дубликатов)
* Отправка сообщений и загрузка истории чата с проверкой прав доступа
* Мгновенная доставка сообщений в реальном времени через `ChatHub`
